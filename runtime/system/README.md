# System

The install, reinstall and uninstall of the factory, as root, from a terminal or, for an upgrade to any commit on
GitHub, from root's upgrade unit. It sets up the machine, the users, the units and the firewall, and connects the
factory to the shared services the server set-up runs. Here too is `factory-own`, which the owner runs with sudo to
commit their own change to a file only a person changes.
