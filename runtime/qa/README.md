# QA

What testers need: which testers a change needs, their findings, the steps they mark and the evidence of their runs,
each tester's own browser with the factory's tools beside it, the standard format of a product's scenarios, each
scenario as slot 0's build has it, and the QA verbs. A task's tester's runs reach the evidence with its result; the regression testers' reach it when the
orchestrator saves the check they walked for. Before a browser tester's result on a change to the screens is taken,
its browser's own recording must show the page at every width the owner set. `replay/` makes each run the owner's
replay once the run is in the evidence. The evidence is kept for the newest merge bundles; the warden's clean-up
removes the rest, and the dashboard then says when it went.
