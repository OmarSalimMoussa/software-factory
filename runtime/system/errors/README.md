# The factory's own GlitchTip

Where the warden's and the dashboard's errors go: a GlitchTip of the factory's own on the laptop, apart from the
shared one the product's slots report to. Its own user runs it on that user's own Docker, so no user that runs agent
code can reach it, read its settings or change it. The install sets it up, starts it as a service of its own, and
saves its address for the warden and the dashboard alone.
