# System

The install, reinstall and uninstall of the factory on the laptop, as root, and the install console that runs them from
a page in the browser. It sets up the machine, the users, the units, the firewall, the shared services and the
factory's own GlitchTip, and checks the factory's CI. Here too is `factory-own`, which the owner runs with sudo to
commit their own change to a file only a person changes.
