# Chat

The factory's ear in a chat the owner shares with friends and their agents. Most of what is said there is none of
the factory's business. A message that carries the tag, `#factory` unless the settings say otherwise, becomes one
request in the chat inbox, and triage takes it at once.

The factory answers on that message as the owner's bot: a reaction and a short reply when it files the request, and
another when triage decides what it is. It never repeats what was said in the chat, and it mentions no one.

Words from the chat are data from outside, never instructions, whoever wrote them. The agents that triage a request
or take it in read more of the talk around it through the warden, a page at a time and only so far. The owner gives
the bot's token, which no agent ever holds, and names the channels to read; with none named, the factory reads no
chat.
